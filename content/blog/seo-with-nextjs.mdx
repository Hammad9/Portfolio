Next.js gives developers powerful tools for SEO. Here is how to use them effectively.

## Metadata

Use the Metadata API to set titles, descriptions, Open Graph tags, Twitter cards, and canonical URLs. Export metadata from layouts and pages, and use generateMetadata for dynamic routes.

## Dynamic Routes

For blogs, projects, and case studies, use generateStaticParams to pre-render pages at build time. This gives you fast, indexable URLs.

## Sitemaps and Robots

Create sitemap.ts and robots.ts in your app directory. These inform search engines about your pages and crawling rules.

## Structured Data

Add JSON-LD for Person, Website, Article, and CreativeWork schemas. Rich results improve click-through rates and help search engines understand your content.

## Performance

Fast sites rank better. Optimize images, use server components, and minimize JavaScript to improve Core Web Vitals.

SEO is a mix of technical excellence and useful content. Get the foundation right and keep publishing value.
